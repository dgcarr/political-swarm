# Political Swarm v0.1.0

Political Swarm is a Claude Code plugin and controlled experiment in multi-agent governance. It delegates coding tasks to OpenRouter models under one of three systems: Westminster-inspired democratic committees and votes; socialist specialist guilds with peer review and recallable leadership; or a capitalist task market with bids, capital accounts, spending decisions, and escrow.

## Highlights

- Claude Code remains the human-facing supervisor through the bundled MCP server and slash commands.
- Agents work in isolated Git worktrees; `/swarm-apply` presents the controlled, explicitly human-approved route into the real repository.
- Configurable model selection, per-task/per-run budgets, and a non-bypassable hard spending ceiling.
- Thirteen MCP tools for runs, decisions, diffs, application, model configuration, and the loopback-only live dashboard.
- Reproducible five-strategy benchmark harness with preserved run state, ledger, patch, worktree snapshot, and metrics.
- Unit tests plus zero-cost and real-model smoke suites.

## Testing status

The TypeScript build and unit suite are intended to pass on Node.js LTS. Dashboard smoke tests require no API key. Strategy, engine, MCP, and budget smoke tests invoke real OpenRouter models and can incur cost; release validation should record exactly which were run.

## Known limitations

- Model output is nondeterministic and must be reviewed as untrusted code.
- Worktrees isolate Git changes but are not a security sandbox for arbitrary commands.
- MCP cannot cryptographically distinguish a human-directed request from an autonomous request by Claude; apply protection is procedural and permission-based.
- Benchmark comparisons depend on model availability, configuration, and controlled repeated runs. No performance claims are included until results are collected.
- Outside the benchmark harness, the built-in task verification command (`config/checks.yaml`) expects `npm test --silent`, so non-Node projects need a package script adapter. The benchmark harness injects its own Python check configuration for the Python fixture.
