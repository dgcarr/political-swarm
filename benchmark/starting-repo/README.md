# alloydamage — starting point

This repository is the shared starting point for the political-swarm coding-swarm benchmark.

See `TASK.md` for the full task specification.

`data/` contains pre-fetched, locally-supplied neutron displacement-damage cross-section data
for Fe, Cr and Ni — see `data/<element>/PROVENANCE.md` in each subdirectory for source details.
Do not fetch different or additional nuclear data from the internet; use what is provided here.
